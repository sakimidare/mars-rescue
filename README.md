# 火星救援

## 一、项目简介

本项目是一个基于 NoneBot2 框架开发的 QQ 机器人插件，用于检测 QQ 群聊中是否发送过相似的图片。  
当群成员发送图片时，插件会自动提取图片的视觉特征，并与历史图片进行相似度比对；若检测到相似图片，则引用该图片在当前会话中第一次出现的消息位置并进行提示。

---

## 二、功能概述

- 监听 QQ 群聊与私聊中的图片消息  
- 使用感知哈希（Perceptual Hash，pHash）算法提取图片特征  
- 基于汉明距离判断图片相似度  
- 若检测到相似图片：
  - 引用最早出现该图片的消息
  - 返回相似度提示信息
- 使用 SQLite 数据库持久化存储图片特征
- 自动过滤 GIF 与动画表情，避免无效计算

---

## 三、NoneBot 启动机制说明

### 3.1 NoneBot2 框架概述

NoneBot2 是一个异步、事件驱动的 Python 聊天机器人框架，其核心设计思想包括：

- 由 Driver（驱动）管理程序生命周期
- 由 Adapter（适配器）对接具体聊天平台协议
- 将外部消息统一抽象为事件并分发给插件处理

本项目基于 NoneBot2，并使用 OneBot v11 适配器与 QQ 协议实现进行通信。

---

### 3.2 启动流程说明

项目的启动入口位于 `main.py`，其运行流程可以概括为以下几个步骤：

1. 初始化 NoneBot 全局配置与事件系统  
2. 获取当前运行环境的驱动实例  
3. 注册 OneBot v11 适配器  
4. 加载插件并注册事件处理器  
5. 启动事件循环，进入消息监听状态  

整个系统启动后，机器人将持续运行并等待外部消息事件的到来。

---

### 3.3 正向 WebSocket 通信模式

本项目使用 OneBot v11 协议中的正向 WebSocket 模式进行通信，其基本架构如下：

```
QQ 客户端  
↓  
QQ 协议实现（如 go-cqhttp、NapCat 等）  
↓ 正向 WebSocket  
NoneBot2（本项目）
```

在正向 WebSocket 模式下：

- NoneBot 作为 WebSocket 客户端
- 主动连接到 QQ 协议实现所提供的 WebSocket 服务
- QQ 后端通过该连接向 NoneBot 推送消息事件

该模式结构清晰，便于本地部署与调试。

---

### 3.4 消息事件处理流程

以一条群聊图片消息为例，其完整处理流程如下：

1. 群成员在 QQ 群中发送图片  
2. QQ 协议实现接收并解析消息  
3. 通过 WebSocket 将消息事件推送至 NoneBot  
4. OneBot v11 适配器将其转换为统一的消息事件  
5. NoneBot 将事件分发给已注册的插件  
6. 图片相似度检测插件捕获事件并执行检测逻辑  

该流程体现了事件驱动系统的基本工作模式。

## 四、图片相似度检测原理

### 4.1 感知哈希算法

感知哈希是一种用于衡量图片视觉相似性的算法，其目标并非判断图片是否完全一致，而是判断其在整体视觉结构上的相似程度。

该方法通常包括以下步骤：

1. 对图片进行统一预处理  
2. 提取低频视觉特征  
3. 将特征映射为固定长度的哈希值  
4. 使用汉明距离衡量不同图片之间的差异  

当两张图片的汉明距离小于设定阈值时，即认为它们是相似图片。

---

### 4.2 相似度阈值设定

本项目中采用固定的汉明距离阈值进行相似度判定。  
阈值越小，判定条件越严格；阈值越大，检测结果越宽松。

在实验过程中，该阈值能够在误判率与漏判率之间取得较好的平衡。

## 六、数据库设计与工程实现

### 6.1 数据存储内容

插件使用 SQLite 数据库存储以下信息：

- 图片的感知哈希值  
- 图片首次出现时对应的消息 ID  
- 群号（用于区分不同会话）  
- 图片文件标识  

通过数据库持久化方式，保证机器人重启后仍可进行相似度检测。

---

### 6.2 会话隔离机制

为避免不同群聊或私聊之间的相互干扰，插件采用会话隔离设计：

- 群聊以群号作为会话标识  
- 私聊使用空会话标识进行区分  

相似度检测仅在当前会话范围内进行，保证检测结果的合理性。

---

### 6.3 数据一致性控制

数据库中通过联合唯一约束保证同一会话中不会重复存储相同图片的特征信息。  
当检测到重复插入时，程序会进行安全处理而非直接报错，从而提高系统稳定性。

## 七、运行方式

在完成 QQ 协议实现与 WebSocket 配置后，可通过以下方式启动机器人：
- 运行：
  ```bash
  pip install -r requirements.txt
  ```
  以安装必要的依赖（虚拟环境和部分系统接管 pip 包的 Linux 发行版请自行寻找安装方法）
- 在 `.env.prod` 里面填写必要字段（包括`ONEBOT_ACCESS_TOKEN` 和 `ONEBOT_WS_URLS`）以确保 NoneBot 能够正向链接到 WebSocket 服务器。
- 直接运行 `main.py` 文件。

启动后，机器人将自动进入消息监听状态。

## 八、隐私与伦理说明

- 插件仅处理用户在聊天中主动发送的图片内容  
- 不进行人脸识别、身份识别或内容分析  
- 图片数据不上传至任何第三方服务  
- 数据仅用于图片相似度检测目的  

该设计遵循人工智能系统中的最小必要性原则。
